# ADR-0002 — Opensource-first: community-стандарты как начинки модулей

| | |
|---|---|
| **Статус** | accepted (user + оракул, 2026-07-11) |
| **Контекст** | у предка (capsule) половина vite-builder — самописная импорт-логика; боли DX: нет Ctrl+Click-навигации (WebStorm), ребут dev-сервера для новых файлов, плавающая типизация, перегруз билдера |

## Решение

**Всё, что закрывается проверенным community-стандартом, — берём его; своё
пишем только там, где наш концепт реально уникален.** Взятое оформляется как
НАЧИНКА модуля за нашим контрактом (механика интеграций ADR-0001): заменить
своим потом = написать вторую начинку, не вскрыть движок. Community-тул
заодно даёт best-practice-планку для будущей замены.

## Конкретика build-infra (исполняется на шаге «инфра-плагины», после ит.1)

| Контракт модуля | Начинка | Что чинит |
|---|---|---|
| «конвенции скана → реестр слоёв + типы» | **unimport / unplugin-auto-import** (antfu, стандарт Nuxt-мира) | watch новых файлов без ребута; атомарные стабильные d.ts (типы не едут); реестр генерится НАСТОЯЩИМ модулем с re-export'ами — навигация в источник (не `declare global` поверх globalThis) |
| «pages-конвенция → routeTree» | **@tanstack/router-plugin** (file-based, официальный) | самописный RouterPlugin предка умирает целиком |
| HMR-обёртка фабрик | своё (уникальный концепт, маленький transform) | — |

Цель: >половины логики vite-builder предка не переносится вообще.

## Guardrail

Если после пересадки на community-стек боли DX остаются — это сигнал о цене
самого канона «без импортов»: тогда ADR-разговор о каноне (например, глобалы
только в слоях, реестры импортируемые), а НЕ третий слой самописного кодгена.

## Прецеденты принципа в экосистеме

Kobalte вместо hand-rolled примитивов (kit) · sherif/knip/publint вместо
самописных аудитов · nx release вместо ~740 строк release-local предка ·
goose/sqlc в Go-каноне.
